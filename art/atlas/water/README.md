Inspect `water-comparison.png` at full width and the three `water-?-preview.gif` loops. The comparison is editable VectorCraft art, with each treatment's vector source embedded. All retain the selected sea background `#d8e7e3`.

| Proposal | Character and trade-off |
|---|---|
| A · Quiet currents | Long, smooth horizontal lines and slight wave motion. A calm sea with a stronger directional rhythm. |

No imported game art, stock texture, external generator, paid call or procedural runtime drawing was used. EffectCraft0.24.1 authored the motion in `water-treatments.ecproj`: composition1/layer3(A), composition34/layer36(B), composition67/layer69(C). A uses Wave Warp(height2,width150,direction90,pinningall edges); B uses Ripple(radius100,wave width150,height2); C uses Wave Warp(height3,width110,direction75,pinningall edges).
