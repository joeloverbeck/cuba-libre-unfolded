## Editable sources and exports

`atlas-terrain-textures.vectorcraft` has three256×256 artboards: grassland, forest, mountain. Export at2pixels/point to the matching `atlas-terrain-{grassland,forest,mountain}.png`. Each seamless tile retains the accepted profile fill (#d9d9a1/#91b59a/#c7b19a) and two sparse original engraved motifs. VectorCraftCLI0.24.1; editor checkout9ddbf25bef7711c3404549d95b730f7dec3210e7, not independently verified binary provenance. No imported texture images.

`atlas-terrain-map.blend` derives from the accepted `atlas-map.blend`. Blender5.2.3 applied planarUVs `(world.x/1.15,world.y/1.15)` to the seven province meshes. Only faces with upward normalz>0.99 receive a new textured material; side and bevel materials, vertex coordinates, region names, cities and ECs are preserved. Forest: Pinar del Río, Camagüey Province, Oriente; grassland: La Habana, Matanzas; mountain: Las Villas, Sierra Maestra. The exact same vertex coordinates were checked before saving. Textures are packed in the editable source with portable sibling image paths. Export the active Cuba_Atlas_Regions scene only, selection of all13regions, apply modifiers, GLB, no cameras/lights. `atlas-terrain-map.glb` contains one scene,13nodes and three embedded PNGs, no external buffers. No live Blender document or original source was overwritten.

`atlas-terrain-labels.vectorcraft` derives from accepted Atlas labels. Terrain/city words and bare population line are removed for all ten cities/provinces. Original name lettering remains; beneath it the selected ivory capsule contains a person and numeral. Badge geometry is55% of the study's84×44 component. Artboard0 is the full map-coordinate arrangement; artboards1–13 follow `terrain-labels.json`, exported at3pixels/point to `atlas-terrain-label-{space}.png`. Labels retain previous x/y/width and piece placement, with city/province height52for the badge; EC bounds/values remain unchanged. Source reopens without missing links/warnings. Existing font license applies.

`terrain.sha256` requires the self-contained GLB, label metadata and all13label exports. Original runtime assets and save-bound identity remain unchanged; terrain is stateless presentation. Runtime loads this scene and its labels through the existing Bevy material/plane paths, and still uses the shared counted solid pieces. Original profile adjacency/shape and rules data remain authoritative for their respective facts.
